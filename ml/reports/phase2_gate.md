## Notes

- Late batches = batches that reached the server after a later batch of the same trip (freshest-first after outages, ADR-010). `late_data` trips were assembled, then re-assembled when an older batch arrived.
- The local API ran with `INGEST_SIM_CLOCK=true` (the server clock follows the simulation; refused in production) and a raised rate limit (429s are unit-tested).
- Faults use faster curves than the library defaults so codes appear inside one week; the ground truth is from `Timeline.ground_truth()`.
